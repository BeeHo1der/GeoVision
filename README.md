# GeoVision AI

Локальный MVP помощника геолога для сегментации палеорусел. Сайт принимает
одно или несколько изображений, строит маску и карту вероятности, выполняет
предварительный объёмный расчёт и предлагает перспективные координаты скважин.

## Что уже реализовано

- пакетная загрузка PNG, JPG и TIFF;
- инференс `U-Net + ResNet-34` через `segmentation_models_pytorch`;
- загрузка `best.pth` из raw `state_dict` или словаря checkpoint;
- бинарная маска и цветная карта вероятности;
- карта вероятности в абсолютной шкале: синий — низкая, красный — высокая;
- ручная коррекция маски кистью и ластиком с повторным расчётом;
- расчёт площади, нефти в пласте, извлекаемого объёма и валовой стоимости;
- автоматические сценарии количества скважин: минимум, оптимально, максимум;
- подбор скважин по новой покрываемой территории;
- радиус влияния одной скважины — 500 м;
- минимальное расстояние между центрами — 1000 м;
- относительные или привязанные координаты;
- демонстрационный режим для проверки интерфейса без весов.

> Демонстрационный режим не является ML-прогнозом. Он явно отмечается в
> интерфейсе и используется только до подключения настоящего `best.pth`.

## Установка

Требуется Python 3.11–3.13.

Полная пошаговая инструкция для Windows находится в
[`WINDOWS_MODEL_GUIDE.md`](WINDOWS_MODEL_GUIDE.md).

### Windows PowerShell

```powershell
cd geology_assistant
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
Copy-Item .env.example .env
python main.py
```

Откройте <http://127.0.0.1:8000>.

В Windows также можно запустить `setup_windows.bat`, а после установки —
`start_windows.bat`.

### Linux

```bash
cd geology_assistant
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
cp .env.example .env
python main.py
```

## Подключение модели

Положите checkpoint в корень проекта:

```text
geology_assistant/best.pth
```

Текущий загрузчик создаёт модель так:

```python
smp.Unet(
    encoder_name="resnet34",
    encoder_weights=None,
    in_channels=3,
    classes=2,
    activation=None,
)
```

`clDICE` нужен во время обучения и не добавляется в инференс. После выхода
модели применяется `softmax`, из него берётся класс `1`. Пользовательский
порог в интерфейсе отсутствует: бинарный класс определяет сама U-Net.

Исходный `best.pth` содержит состояние оптимизатора и NumPy-метрики. Для сайта
рекомендуется один раз создать облегчённый checkpoint:

```cmd
python checkpoint_tool.py inspect best.pth --trust
python checkpoint_tool.py convert best.pth best_inference.pth --trust
```

После этого укажите в `.env`:

```text
MODEL_PATH=best_inference.pth
TRUST_MODEL_CHECKPOINT=false
```

Для отключения демонстрационного режима укажите в `.env`:

```text
ALLOW_DEMO_MODE=false
```

## Как выбираются скважины

1. U-Net определяет бинарную маску палеорусла.
2. Из принятой маски строится центральная линия.
3. Кандидаты ближе 500 м к концам линии исключаются, если длина объекта это
   позволяет.
4. На оставшейся линии через каждые 50 м создаются кандидаты.
5. Вокруг каждого кандидата строится круг радиусом 500 м.
6. Выбирается точка, покрывающая максимальный новый извлекаемый объём.
7. Следующие центры размещаются не ближе 1000 м.
8. Слабые последние кандидаты отбрасываются автоматически.
9. Из ранжированного ряда строятся сценарии: минимум, оптимально и максимум.

После ручной коррекции синей маски этот алгоритм выполняется повторно. Поля,
добавленные геологом, считаются принятыми и участвуют в объёмном расчёте.

## Проверенная конфигурация best.pth

- `segmentation_models_pytorch.Unet`;
- энкодер ResNet-34;
- 3 входных RGB-канала;
- 2 выходных класса;
- класс палеорусла — индекс `1`;
- ImageNet-нормализация;
- размер входа сайта — `512 × 512`;
- loss при обучении — `Combined clDICE`.

## Ограничения MVP

- объём и стоимость зависят от введённых параметров и не являются официальной
  оценкой запасов;
- круг 500 м — заданное упрощение, а не гидродинамически рассчитанный радиус;
- координаты являются целями для экспертной проверки, а не готовым проектом
  бурения;
- при геопривязке X и Y должны быть заданы в метрической системе координат.
